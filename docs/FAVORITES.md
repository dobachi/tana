# お気に入り（FR-05, FR-06）

サイドバー下段。よく行く場所（手元・リモートどちらも）を登録しておき、クリックか `Enter` で開く。

## 登録・整理

- **`Ctrl+D`**: 今いるフォルダを登録（名前の既定は末尾の階層名、リモートは `k16:notes`）
- **＋** ボタン: フォルダを作る。フォルダは入れ子にできる
- **ダブルクリック**: 名前を変える / **`t`**: タグを編集（空白区切り、空欄で外す）/ **×**: 削除
- 登録日時を覚える（登録日順の並べ替えに使う。この機能より前に登録したものは「最も古い」扱い）

## 並べ替え（⇅ ボタン）

| 並べ方           | 中身                                                                                                                                                                     |
| ---------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------ |
| **手動**（既定） | 自分で決めた並び。**ドラッグ**で前後へ、フォルダの中央へ落とすとその中へ。キーボードは `Alt+↑/↓`（前後）、`Alt+→`（直前のフォルダへ入れる）、`Alt+←`（フォルダから出す） |
| **名前順**       | 数字は数として比べる（`b2` → `b10`）。昇順 / 降順                                                                                                                        |
| **登録日順**     | 昇順＝古い順 / 降順＝新しい順                                                                                                                                            |

自動（名前順・登録日順）のときは、各階層でフォルダを先頭にまとめて並べる。
手動の並びは保存されたまま残るので、手動へ戻せば元の並びに戻る。自動の並べ替え中と絞り込み中は、ドラッグ・`Alt+矢印` では動かさない（案内が出る）。

## まとめ方（⇅ ボタン）

- **まとめない**（既定）: フォルダ構造そのまま
- **接続先でまとめる**: 「このPC」→ 接続先（`k16` など、名前順）の見出しの下に並べる
- **タグでまとめる**: タグごとの見出し（複数タグのものは各見出しに出る）→「タグなし」

見出しはクリック（または `h` / `l`）でたためる。たたんだ状態は覚えている。
見出しの下ではフォルダ構造を保つが、その見出しに入るブックマークを含まないフォルダは出さない。

## 絞り込み

- 検索欄: 名前・パスの部分一致（空白区切りはすべて含むもの）。`#タグ` を混ぜるとそのタグを持つものだけ
- タグのチップ（検索欄の下。タグがあるときだけ出る）: 押すとそのタグで絞り込み、もう一度で外す

絞り込み中は所属フォルダをパンくずで添えた平坦な一覧になる。

## 保存先

`localStorage` の `tana.favorites`（ツリー）と `tana.favorites.view`（並べ方・まとめ方・開閉）。
モデルは `core/favorites.js`、見せ方は `core/favarrange.js`（どちらも純粋・テスト済み）、描画と操作は `core/favoritesview.js`。
